Application Description

The Hospital Records Management System is a practical database application developed using Oracle PL/SQL to manage essential hospital operations, including patient registration, doctor information and specializations, appointment scheduling, medical treatment records, and billing management.

The system is designed to demonstrate the practical application of advanced Oracle PL/SQL programming concepts in a healthcare environment. It incorporates structured database tables, relationships, constraints, stored procedures, stored functions, records, collections, cursors, bulk processing, and exception handling.

The application aims to maintain data integrity, support efficient information management, and demonstrate how PL/SQL can be used to solve real-world database management challenges.

Repository Structure

The project is organized into the following directories and files:

00_schema/: Contains database table creation scripts, relationships, constraints, and sample data insertion scripts.

01_procedures/: Contains stored procedures implementing hospital operations and demonstrating records, cursors, and bulk processing.

02_functions/: Contains stored functions that return meaningful results and calculate aggregate metrics.

03_tests/: Contains test scripts demonstrating successful execution and appropriate error handling.

screenshots/: Contains screenshots of actual Oracle Database execution results.

docs/: Contains implementation explanations, documentation, and performance considerations.

How to Run

To execute the application, follow these steps in Oracle SQL Developer or another compatible Oracle Database environment:

Execute 00_schema/01_create_tables.sql to create the database tables, relationships, and constraints. Use SET DEFINE OFF; if required by the scripts.

Execute 00_schema/02_insert_sample_data.sql to populate the database with sample records.

Compile all stored procedure scripts located in 01_procedures/.

Compile all stored function scripts located in 02_functions/.

Execute the test scripts in 03_tests/, including test_success_cases.sql and test_error_cases.sql.

Verify the execution results and capture screenshots of the successful operations and error-handling tests.

Save the screenshots in the screenshots/ directory.

In Oracle SQL Developer, use F5 (Run Script) to execute scripts containing SQL*Plus commands and display output generated by DBMS_OUTPUT.

PL/SQL Concepts Demonstrated

This project demonstrates the following advanced Oracle PL/SQL concepts:

Records: User-defined records and %ROWTYPE for storing and processing related data.

Collections: Appropriate PL/SQL collection types for storing and processing multiple values or records.

Implicit Cursors: Use of SQL%ROWCOUNT, SQL%FOUND, and SQL%NOTFOUND to monitor database operations.

Explicit Cursors: Retrieving and processing multiple rows using explicit cursor operations.

Bulk Processing: Use of BULK COLLECT and FORALL to improve the efficiency of database operations.

Stored Procedures: Reusable program units that perform meaningful database operations using input and output parameters where appropriate.

Stored Functions: Functions that return meaningful results using SQL and PL/SQL logic.

Exception Handling: Predefined exceptions, user-defined exceptions, and RAISE_APPLICATION_ERROR for meaningful error reporting and reliable application execution.
